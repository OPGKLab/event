# イベントサイト テンプレート 使い方

OPGK Labの「common + 個別ページ」の型を、単発イベント/講座サイト用に応用したものです。

## フォルダ構成

```
common/
  series-style-base.css   ← 共通スタイル。編集しない
  series-shell.js         ← 共通スクリプト(ヘッダー・フッター等)。編集しない
events/
  opgk-lab-howto/         ← 1イベント = 1フォルダ
    event-config.js       ← このイベント用に書き換える設定ファイル
    index.html             トップページ
    content.html           内容ページ(ページ名は自由に変更可)
    links.html              資料・リンクページ
```

## 新しいイベントを作る手順

1. `events/opgk-lab-howto/` フォルダをまるごとコピーし、`events/新しいイベント名/` にリネームする
2. コピーした中の **`event-config.js` だけ** を書き換える
   - `title` / `tagline`:イベント名・一言
   - `date` / `time` / `venue`:決まっていれば入力。**両方空文字のままなら、開催情報欄は自動的に非表示**になるので、常設の解説ページとしても使えます
   - `qrImage`:QRコード画像を用意したらファイルパスを入れる(空なら非表示)
   - `formUrl`:申込み・問い合わせ用のGoogleフォームURL(空ならボタン非表示)
   - `pages`:そのイベントに必要なページだけを配列で指定。1枚スクロールにしたい場合は `top` だけ残す
3. 各HTMLファイル(`index.html` など)の `<main>` 内の文章を、そのイベント用に書き換える
   - ページを増減したいときは、HTMLファイルを追加/削除し、`event-config.js` の `pages` 配列も合わせて編集する
4. GitHubの新しいリポジトリを作り、`common/` フォルダと `events/` フォルダをWeb UIからアップロードする
5. リポジトリの Settings → Pages で公開を有効にする
6. 公開URLを控えておき、必要ならOGP用の `og:url` などのmetaタグをHTML内で実際のURLに書き換える

## 覚えておきたいポイント

- Publicリポジトリなので、URLを知っていれば誰でも中身を読めます。公開前提の内容だけを置いてください
- `common/` を編集すると、そのリポジトリ内の**すべてのイベントページ**に影響します。デザインを揃えて一括更新したいときだけ触ってください
- 終わったイベントのフォルダは、消さずに残しておけばアーカイブとして機能します(URLも生き続けます)
