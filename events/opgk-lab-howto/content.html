コマンドライン(gitコマンド)は使わず、GitHubのWeb画面だけで進めました。 つまずいた順番のまま並べています。

  1. 1

    GitHubアカウントとリポジトリを作る

    GitHubに無料登録し、新しいリポジトリ(ファイルを置く箱)を1つ作成します。 公開して問題ない内容だけを置く前提で、公開設定は「Public」にしました。

    Publicリポジトリは、URLを知っている人なら誰でも中身を読めます。 この講座サイトも含め、公開前提の内容だけを置くようにしています。

  2. 2

    Web画面からファイルをアップロードする

    手元のパソコンでHTML/CSS/JSファイルを用意し、GitHubのリポジトリ画面の 「Add file → Upload files」からドラッグ&ドロップでアップロードしました。 ゲーム1本ごとにフォルダを分け、共通部分(common)は1か所にまとめています。

  3. 3

    GitHub Pagesを有効にして公開する

    リポジトリの Settings → Pages から、公開元のブランチを指定するだけで、 https://ユーザー名.github.io/リポジトリ名/ の形で無料公開されます。 サーバーの契約やお金は一切かかりません。

  4. 4

    OGPタグでリンクプレビューを整える

    LINEやSNSでリンクを共有したときに、タイトル・説明文・画像がきれいに 表示されるよう、各ページの<head>にOGP用のmetaタグを 追加しました。地味ですが、人に紹介するときの印象が大きく変わります。

  5. 5

    コミット履歴を見る・安全に元に戻す

    ファイルを更新するたびに履歴が残るので、「いつ・何を変えたか」を あとから確認できます。変更が失敗したときも、以前のバージョンに 戻す操作がWeb画面から行えると分かり、安心して手を動かせるようになりました。

    最初は「壊したら戻せないのでは」と不安でしたが、 この仕組みを知ってからは気軽に試行錯誤できるようになりました。
